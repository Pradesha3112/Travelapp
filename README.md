# 🌍 WanderLog - Travel Planner
## ✨ Features

- **Beautiful Dashboard:** Overview of all trips with statistics
- **Trip Management:** Add, edit, view, and delete trips
- **Smart Budget Breakdown:** Automatic allocation of budget across categories
- **Weather Prediction:** Destination-specific weather forecasts
- **Packing List Generator:** Smart suggestions based on trip type and weather
- **Countdown Timer:** Days until your next adventure
- **Attractions Guide:** Popular places to visit at your destination
- **Travel Tips:** Helpful advice for each destination
- **Search Functionality:** Find trips by destination or country
- **Responsive Design:** Works perfectly on mobile and desktop

---

## 🛠️ Technologies Used

- **Backend:** Python 3.12, Flask 3.0
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3, JavaScript
- **Icons:** Font Awesome 6
- **Fonts:** Google Fonts (Poppins)

## 🚀 How to Run

### Prerequisites
- Python 3.8 or higher installed
- pip (Python package manager)

### Step 1: Clone or Download
```bash
git clone https://github.com/yourusername/wanderlog-travel-app.git
cd wanderlog-travel-app
```

### Step 2: Install Dependencies
```bash
pip install -r requirements.txt
```


### Step 3: Run the Application
```python app.py
```
